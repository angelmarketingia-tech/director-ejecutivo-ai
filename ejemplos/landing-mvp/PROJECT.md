# Daptux.IA — Landing Page

## Objetivo
Crear una landing page de una sola página, moderna y sobria, para **Daptux.IA**, agencia colombiana que desarrolla sitios web para negocios. El objetivo es convertir visitantes en prospectos mediante un llamado a acción claro hacia WhatsApp.

## Usuarios
- Dueños de pequeños y medianos negocios en Colombia que buscan presencia digital.
- Emprendedores que aún no tienen sitio web o quieren renovarlo.

## Stack
- **Un solo archivo HTML autónomo** (`index.html`) con CSS y JS embebidos.
- Sin frameworks ni librerías externas.
- Fuentes del sistema (sans-serif moderna) o Google Fonts vía CDN (única dependencia permitida).
- Paleta: oscura/neutra con acento en color vibrante (ej. violeta o azul eléctrico).
